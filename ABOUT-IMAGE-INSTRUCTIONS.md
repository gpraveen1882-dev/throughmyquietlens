# About page image instructions

The redesigned About page is generated by `scripts/build.mjs`.

Replace the placeholder JPEGs in `public/images/about/` while keeping these exact filenames:

- `praveen-portrait.jpg` — vertical portrait, ideally 4:5
- `journey-chennai.jpg`
- `journey-singapore.jpg`
- `journey-united-states.jpg`
- `journey-return.jpg`
- `moment-ucla.jpg`
- `moment-conversations.jpg`
- `moment-service.jpg`
- `moment-family.jpg`
- `moment-dogs.jpg`
- `moment-writing.jpg`

JPG images around 1600 px on the longest edge are sufficient. The layout crops images automatically with `object-fit: cover`. After replacing them, run `npm run build` or deploy through the existing workflow.
