# Through My Quiet Lens

Astro-based publication for throughmyquietlens.com.

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

Cloudflare Pages settings:
- Build command: `npm run build`
- Output directory: `dist`
- Node.js: 20 or newer

Add essays in `src/content/essays/` as Markdown files.
